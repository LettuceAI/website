## Highlights

- **Local image generation** — stable-diffusion.cpp runs as a managed sidecar on your own hardware, with an installer that pulls complete model bundles from HuggingFace, LoRA support, live progress, cancellation, img2img, inpainting, and upscaling
- **Playground** — a dedicated three-pane page for image work: prompt on one side, settings on the other, and a feed of past generations with the exact seed, model, and parameters that produced each one
- **Transactional device sync** — the legacy replication path was replaced end to end, so a sync either applies completely or not at all, instead of leaving partial data behind on failure

## Local Image Generation

- **stable-diffusion.cpp runs locally** as a managed sidecar process, so image generation no longer requires an external provider or an internet connection
- The **model bundle installer** pulls complete setups from HuggingFace, resolving the diffusion model, VAE, text encoders, and architecture together instead of leaving you to assemble them by hand
- **LoRAs** are detected, listed with their trigger keywords, and applied per generation with adjustable strength
- Generations report **live progress**, can be **cancelled mid-run**, and reuse cached model state between runs instead of reloading every time
- **img2img, inpainting, and upscaling** are supported alongside text-to-image
- The model selector and HuggingFace repo search accept **safetensors** files, not just GGUF
- **LiteRouter and custom OpenAI-format image providers** are supported for remote generation, so any endpoint speaking the OpenAI image API works
- sd.cpp **shuts down with the app** instead of surviving as an orphaned process

## Playground

- A **three-pane image workspace**: prompt on the left, settings on the right, and a scrollable feed of everything you have generated
- Each generation card records the **exact seed, model, and parameters** used, so a result you like can be reproduced or nudged
- Random seeds are **materialized at generation time**, meaning "random" results stay reproducible after the fact
- Generation history is written **ahead of the run**, so a crash or force-quit leaves a record of what was in flight rather than losing it
- The recent generations list is **paginated** instead of loading everything at once

## Local Models

- **GPU offload priced from real tensor sizes**: per-unit costs are read out of the GGUF index rather than estimated from layer counts, and the output layer is now recognized as offloading first and costing up to ten times a normal block
- **KV cache sized from per-layer geometry**, including models that mix sliding-window and full attention, using declared head dimensions and ggml block sizes
- The **device compute reserve is measured**, not assumed, and attention scratch space is reserved for query heads rather than KV heads
- **Multi-GPU layer distribution** uses real per-unit costs, and KV is only counted for blocks actually offloaded
- Recommending a VRAM context now **subtracts weights already resident** on the card
- **MTP (multi-token prediction)** models load and fit their bundled draft tensors, with the draft reserve derived from real weights and KV, and configurable placement
- **Custom sampler chains with saveable presets**, plus configurable repeat penalty and penalty range
- **Prompt prefixes are cached across conversations**, so switching chats does not always mean reprocessing the whole prompt
- Speculative decoding **adapts its draft length**, per-token streaming overhead was reduced, and prompt microbatch size is configured separately from the batch size
- **Native inference timings** are reported, and generation throughput is measured correctly
- Qwen **thinking directives** are honored

## Device Sync

- The legacy replication path was **replaced with a transactional sync engine**: changes are captured, planned, and applied as a unit, so an interrupted sync does not leave half-applied data
- Conflicts resolve **last-writer-wins by original creation time**, consistently across every data type
- Sync **refuses to run between mismatched app builds** instead of exchanging data it cannot interpret, and stale sync state is repaired rather than left blocking

## Companion

- A companion's **soul and relationship progress carry across separate chats**, so starting a new conversation no longer resets who they are
- Continuity is **evidence-based**: what changed is recorded with the moments that caused it, instead of a single number that could drift with no explanation
- **Shared memory survives creating a new chat**, and the canonical message timeline is preserved across episodes
- **Turn effects are separated from passive drift**, so a specific exchange and the slow background change no longer overwrite each other
- **Earned relationship progress is preserved** rather than recalculated away
- System-authored message timestamps are **unmistakably marked as such**, and companion timelines stay aligned with the session clock
- The companion cycle status UI now **matches dynamic memory's**

## Group Chats

- Group conversations run on a **unified backend** shared with 1-on-1 chats, with a proper session model behind them
- **Per-character model overrides**: any participant can run on a different model from the rest of the group
- **Group system prompt overrides**, showing the conversational or roleplay template depending on the group's type
- **Branch to a 1-on-1** from any message, with a memory cutoff at that point
- **Classic and detailed list layouts** for the group list, and history scoped to its own group
- Director continuation turns complete properly, and character prompt fallback is honored

## Memory

- **Deterministic rewind**: rewinding a chat restores the memory state as it was at that message, driven by a user-edit event log rather than a best-effort rebuild
- Dynamic memory rebuilds after a rewind are **bounded** instead of cascading
- Manual memory cycles **refresh correctly in branched chats**

## Desktop & Appearance

- **Six navigation layouts**: bottom bar, bottom bar with labels, dock, sidebar, floating sidebar, and header
- The **header is configurable** (auto, attached, floating, inline), navigation can sit on either side or edge, and items can be aligned and reordered
- A **custom title bar** replaces the system one on desktop
- The floating header keeps clear of the status bar, the floating dock centers on mobile, and header style controls stack on narrow screens

## Providers & Usage

- **NanoGPT subscription quota tracking**, including usage reported during streamed completions, with quota meters colored by how close to the limit you are
- **Regenerate a message with a different model** without changing the chat's model
- **Per-model feature generation configs**: sampler overrides for individual features live on the model and are edited from the Generation panel
- Models have a **duplicate action** in their menu

## Fixes

- **Gemini in group chats works again**: on installs where a database column was never created, every Gemini group reply failed outright. The schema is now repaired on launch, and Gemini's thought signatures are retained in group history the same way they are in 1-on-1 chats
- **Gemini fixes across the board**: requested image aspect ratios are honored, v1beta base URLs are preserved, raw tool call names survive round-trips, tool declarations are cached with context, unsupported image edit inputs are rejected with a clear error, and Express aspect ratio and image-block errors surface properly
- **Ollama with strict templates**: stray system messages are normalized so models that reject them stop failing (#85)
- **Cancelled swipe replies stay after their prompt** instead of jumping position
- **Lorebook triggers** match keywords in languages without spaces, and regex triggers fire correctly
- **OpenRouter Gemini completion costs** can no longer come out negative
- **TTS on Windows** no longer flashes espeak console windows, and phonemization runs in a single spawn instead of falling back per segment
- Android no longer uses an **uninitialized platform TLS verifier**
- Smart Creator **preserves drafts** when you open an editor, and settings return paths survive a trip through Playground
- Widgets show **total session message counts** and hide companion-only widgets in roleplay and group chats
- Scene image generation is **gated per model kind**, and an unset scene generation model counts as disabled rather than enabled
- CI builds now **require Ada and Blackwell CUDA kernels** to be present rather than shipping without them
