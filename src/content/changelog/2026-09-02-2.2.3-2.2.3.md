## Highlights

- **Companion template precedence fixed** — companion mode resolves the character's companion prompt template before the session template, so an active session template no longer overwrites the companion prompt
- **Relationship state with meaning** — every axis is now sent as a band, a short behavioral gloss, and the raw score on its scale, instead of a bare label
- **Smart Creator on strict local templates** — models like Gemma that only accept one system message no longer fail during character generation
- **Group chat memory mode sticks** — picking dynamic memory during group creation no longer falls back to manual

---

## Companions

- **Companion prompt template wins over the session template**: previously an active session template took precedence in companion mode and overwrote the companion prompt; the prompt debugger now reports the same source order
- The **relationship-state line** shows each axis as `label - gloss (value on a scale from ...)`, giving the model the word, what it means, and the exact score
- **Trust, closeness, and affection** moved to a seven-step scale, adding bands such as open, avoidant, and indifferent, with trust and closeness keeping a deliberately positive-skewed neutral zone
- **Tension** has named bands from calm to at breaking point instead of being emitted as a bare percentage

## Smart Creator

- On **llama.cpp**, the creation helper's system entries are merged into one leading system message, so chat templates that require a single system message (such as Gemma) no longer fail with "System message must be at the beginning"
- **Remote providers** keep the system entries separate, preserving the authored block structure

## Group Chats

- **Memory mode chosen at creation is kept**: the group is created with the selected mode instead of defaulting to manual, so dynamic memory no longer has to be re-enabled from group settings afterwards
